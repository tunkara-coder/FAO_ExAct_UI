# EX-ACT Gambia Web Portal

A web-based interface for the EX-ACT GHG emissions calculator, tailored for use in The Gambia.

## Features

- **User-friendly Interface**: Simplified design for field agents
- **Offline Capability**: Work without internet connection
- **Multi-sector Support**: Agriculture, LULUCF, Energy sectors
- **Real-time Calculations**: Instant GHG emissions results
- **Data Export**: PDF reports and data exports
